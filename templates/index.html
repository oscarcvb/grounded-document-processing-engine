Grounded Document Processing Engine

Upload an Excel workbook containing Questions and Context sheets. The system will answer questions using only the provided context and return a completed workbook.

1. Download the test file

Download the sample workbook to test the document-processing workflow.

Download Test File

2. Review the workbook

Review the existing questions and optionally replace them with your own. Each workbook may contain a maximum of 5 questions.

Note: This demo uses a free-tier language model. Processing may take approximately 20–30 seconds.

3. Upload the workbook

4. Wait for the file to process

Keep this page open while the workbook is processed. The completed workbook will download automatically when processing is finished.
